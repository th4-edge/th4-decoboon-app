# 团队负责人视角业务闭环与强交互

> 角色：`TeamLeader`（团队负责人）  
> 数据范围：当前企业 `Company` + 当前团队 `Team`  
> 定位：对团队客户转化、报价推进、项目履约、施工计划、现场动态、消息通知和成员业绩负责

## 1. 角色边界与服务端强权限

团队负责人不是“缩小版老板”，而是围绕团队经营闭环承担第一责任：

- 客户：查看当前团队全部客户，跟进团队客户并在量房后安排本团队设计师。
- 报价：查看团队客户报价，可创建、提交、接受或驳回团队报价；不能将报价转为项目。
- 项目/工地：查看由团队客户产生的全部项目，以及项目阶段、任务、计划和现场动态。
- 计划：只读项目施工计划，不修改老板或设计师编排的计划。
- 消息通知：只读取发送给当前登录员工的业务通知；团队通知由服务端按 `teamId` 实时生成。
- 业绩：查看团队汇总指标及每名成员的客户、跟进、报价、项目、任务和现场动态表现。
- 团队：查看本团队成员；可邀请顾问、设计师、项目经理加入当前团队。

所有查询、详情、更新、删除动作均由服务端重新加载当前员工并解析 `DataScope(Team)`。前端隐藏按钮只负责交互体验，不能替代权限。

## 2. 团队负责人邀请注册闭环

### 2.1 从企业负责人发起

1. 企业负责人使用 `18660219918 / 123456` 登录小程序。
2. 进入「我的 → 邀请员工加入」或工作台「邀请成员」。
3. 选择「团队长」，填写被邀请人手机号。
4. 选择已有团队，或填写新团队名称。
5. 后端创建邀请；新团队场景先由企业负责人作为临时队长占位，确保组织关系完整。
6. 被邀请人打开分享链接，完成姓名与密码设置。
7. 接受邀请时，服务端原子完成员工创建、凭证绑定和 `Team.leader` 回写。
8. 被邀请人登录后，`user/info` 返回企业、门店和团队对象，前端进入团队负责人工作台。

### 2.2 团队负责人邀请团队成员

1. 团队负责人进入「我的 → 邀请员工加入」。
2. 只能选择顾问、设计师、项目经理。
3. 服务端强制使用当前登录人的企业、门店和团队，忽略前端伪造 `teamId`。
4. 成员接受后自动继承团队归属，随后出现在团队业绩和团队派单页。

## 4. 核心业务闭环

### 4.1 客户经营闭环

```text
团队客户登记 → 首联/跟进 → 约定量房 → 团队派单
→ 设计师接手 → 报价推进 → 客户接受报价 → 项目立项
```

- 客户分页由 `DataScopeRequestFilter` 自动追加 `com_id + team_id`。
- 客户详情使用 `DataScopeContext + DataScopeSpecification`，越权返回 404。
- 团队负责人只能把客户指派给本团队成员中的设计师。
- 指派成功后刷新客户列表、设计师负荷并生成设计师/顾问通知。

### 4.2 报价到项目闭环

```text
团队客户 → 创建报价 → 提交客户 → 接受/驳回 → 设计师或老板转项目
```

- 团队负责人可查看团队全部报价，但报价金额仍由后端套餐与折扣计算。
- 团队负责人提交、接受、驳回报价时，服务端同时校验报价客户的团队归属。
- 报价转项目保留给设计师或企业负责人，避免团队负责人绕过项目立项规则。

### 4.3 工地履约闭环

```text
项目立项 → 阶段计划 → 施工任务 → 现场汇报 → 阶段验收 → 完工
```

- 项目、阶段、任务、现场动态、验收和成员均通过 `ProjectAccessContext` 校验。
- 团队负责人可见项目全貌，计划与施工动作仍由对应岗位执行。
- 停工项目和逾期任务由通知上下文实时归集到团队负责人通知中心。

### 4.4 业绩闭环

团队业绩报告实时聚合，不新增人工可篡改的业绩表：

- 签约额：当前团队项目合同金额汇总。
- 报价接受率：已接受/已转项目报价 ÷ 团队报价总数。
- 客户结构：团队客户、待量房、今日待跟进、逾期未跟进。
- 项目结构：待开工、施工中、待验收、停工、完工。
- 成员排名：按逾期任务升序、签约额降序形成团队经营关注顺序。

## 6. 强交互规则

- 首页不展示无动作数据；每个风险指标都能跳转到可处理页面。
- 派单、邀请、跟进、报价推进均展示 loading，成功后重新请求服务端。
- 列表使用骨架屏、空态、错误态和下拉刷新，不把网络失败伪装成空数据。
- 状态变化以服务端返回值与二次查询为准，前端不自行猜测流转结果。
- 详情页保留业务上下文，不返回无关完整归属树，降低懒加载 SQL 与信息泄露风险。
- 通知未读数与团队风险指标在页面显示时实时刷新。

## 7. 验收路径

1. 企业负责人邀请团队负责人，选择“新建团队”并完成接受注册。
2. 使用团队负责人账号登录，检查企业、门店、团队归属和角色横幅。
3. 邀请顾问、设计师、项目经理加入团队。
4. 分别验证团队客户列表、客户详情、派单、报价、项目、计划、动态。
5. 验证通知中心只出现本团队风险与当前员工通知。
6. 打开团队业绩，核对成员数、客户数、报价接受率、签约额和逾期任务。
7. 使用其他团队或企业账号访问同一条详情，预期返回 403/404，不泄露归属数据。
