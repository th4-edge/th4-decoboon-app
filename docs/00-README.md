## 当前代码入口

- 页面：`src/pages/**`
- 角色配置：`src/roles/catalog.ts`
- 前端权限：`src/roles/permission.ts`
- 领域实体与访问层：`src/domains/<domain>/{model,api,meta}.ts`
- 全局设计 Token：`src/uni.scss`、`src/styles/base.scss`
- 统一线性图标：`src/components/JzIcon.vue`
- HTTP 协议：`src/core/http.ts`
- 页面路径常量：`src/config/index.ts`
