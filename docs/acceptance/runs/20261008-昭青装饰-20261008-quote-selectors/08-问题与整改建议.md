## 详情

### XA-20261008-001 方案选择器漏读详情

- 根因：`design/scheme/page` 不返回 `spaces/items`，选择器未回读 `design/scheme/info`。
- 修复：方案选择器对每个摘要回读完整方案。
- 验证：真实页面显示 5 个区域、67 个分项、可报价，并成功回填报价页。
- 状态：VERIFIED。

### XA-20261008-002 套餐行保存 orphanRemoval

- 根因：`PackageConfigContext.recalculate` 直接替换带 `orphanRemoval` 的持久化集合。
- 修复：保留原集合，`clear/addAll`。
- 验证：`pack/line/save` 成功，`pack_line=1`，模板成本 `27.40`。
- 状态：VERIFIED。

### XA-20261008-003 测试数据补充

- 处理：本地 dev 补充 1 个最小套餐模板。
- 验证：套餐选择器显示模板并成功回填。
- 状态：CLOSED。

### XA-20261008-004 合同已有计划覆盖新选择

- 类别：BUG / P2
- 状态：FIXED_PENDING_VERIFY
- 现象：从合同创建页选择新的付款/施工计划后，返回页面仍显示原合同计划。
- 根因：`onShow -> load -> selectQuote` 从已有合同重新赋值 `paymentPlanCode/constructionPlanCode`，覆盖刚回传的选择。
- 修复：仅当计划编码为空时，才从已有合同回填。
- 验证：`npm run type-check` 通过；计划选择页面本身已验证 PASS；最终合同页回填需再做一次稳定 DevTools 复点击。
