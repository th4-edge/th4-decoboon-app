## 4. 业务/架构待裁决

- `PackageSection` 当前只属于企业，不属于套餐模板。需要确认套餐分区是“企业共享分区库”还是“每个套餐独立分区”。
- 如果采用企业共享语义，修复后所有未删除分区都会出现在每个套餐配置页；需要补分区复用、重命名和删除治理。
- 如果采用套餐独立语义，需要增加套餐与分区的归属关系；该方案涉及 DDL 和数据迁移，不能并入本次纯前端热修。

## 5. 本次热修范围

1. 套餐配置页独立读取 `pack/section/page`，不再从项目行反推分区。
2. 新增/重命名分区后使用服务端返回对象立即回显，再刷新服务端数据。
3. 有项目行的分区在前端直接阻止删除，并提示先移动或删除项目行。
4. 版本提升到 `1.0.74 / 174`。
