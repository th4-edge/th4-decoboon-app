# 生产文件上传域名排查（2026-09-26）

## 现象

- 开发环境文件上传正常；
- 线上普通接口正常，但头像、工地照片、量房照片、验收照片、设计附件等**所有文件上传**都提示“网络异常，请检查网络”；
- 服务端应用日志没有对应上传接口异常，Nginx 也看不到小程序发来的 `file/private/grant` 请求。

## 根因

微信小程序把网络能力拆成多个独立合法域名：

| 能力 | 使用场景 | 是否需要单独配置 |
| --- | --- | --- |
| `request` | JSON 接口、登录、业务查询 | 是 |
| `uploadFile` | `uni.uploadFile`、头像和照片上传 | 是，且**不会**被 `request` 域名自动覆盖 |
| `downloadFile` | 下载 PDF、附件 | 是 |

开发环境微信开发者工具默认关闭域名校验，所以开发正常；生产客户端会严格校验。若只配置了 `request` 合法域名，普通接口可用，但所有 `uploadFile` 会在请求发出前直接失败，表现为统一的“网络异常”。

当前业务上传统一走：

```text
https://decoboon.joytsing.com/api/file/private/grant
https://decoboon.joytsing.com/api/user/user/update
```

因此只有业务域名需要加入 `uploadFile` 合法域名，不需要把阿里云 OSS 域名直接加入客户端白名单。

## 生产修复步骤

1. 登录微信公众平台，进入对应小程序；
2. 打开“开发管理 -> 开发设置 -> 服务器域名”；
3. 在 **uploadFile 合法域名**中添加：

```text
https://decoboon.joytsing.com
```

4. 确认 **request 合法域名**、**uploadFile 合法域名**、**downloadFile 合法域名**都包含 `https://decoboon.joytsing.com`；
5. 域名只能填 HTTPS 协议和主机名，不能带 `/api/` 路径、端口或查询参数；
6. 配置保存后重新打开小程序，分别验证员工头像、单图上传、多图上传和文件附件上传。

## 证据与验证

服务端上传链路可用时，无有效 token 的小文件探测应返回业务错误而不是 404、413 或连接失败：

```bash
curl -sS -D - -o - -X POST   -H 'token: upload-probe-invalid'   -F 'businessType=Report'   -F 'file=@/tmp/upload-probe.txt;type=text/plain'   'https://decoboon.joytsing.com/api/file/private/grant'
```

生产日志应能看到 `POST /api/file/private/grant` 访问记录。

如果配置完成后仍失败：

- `uploadFile:fail url not in domain list`：仍缺少 uploadFile 合法域名；
- `uploadFile:fail ssl handshake` / 证书错误：检查业务域名证书链；
- 413：检查 Nginx `client_max_body_size`；
- 500：再结合后端 `file/private/grant` 日志排查 OSS 配置。

## 发布门禁

每次正式发布前必须人工确认：

- [ ] 微信公众平台 request 合法域名包含正式 API 域名；
- [ ] 微信公众平台 uploadFile 合法域名包含正式 API 域名；
- [ ] 微信公众平台 downloadFile 合法域名包含正式 API 域名；
- [ ] `urlCheck=true` 时开发者工具无域名报错；
- [ ] 真机完成头像和多图上传验证。

仅配置 `request` 域名不得视为上传域名已配置。
