## 一、现状诊断

1. **设计 Token 体系完整**：`uni.scss` 覆盖品牌/语义/文字/表面/阴影/圆角/间距/字号，主色 `#16A394` 克制动人，符合家装"专业、可信"定位。

## 二、总体设计原则（四条主线）

1. **一屏一主操作**：每屏只有一个 primary 主按钮（推进当前业务阶段的动作）；其余全部降级表达。
2. **动作分级表达**：建立"主操作 → 次级操作 → 图标按钮 → 文字链接"四级体系，用形态而非数量表达优先级。
3. **高频动作图标化、低频动作文字化**：电话/复制/编辑/删除/关闭/更多等高频通用动作用图标按钮；业务推进类（生成报价、合同生效、提交验收）绝不用图标替代。
4. **组件化收敛 + Token 纪律**：重复的私有样式抽组件/语义类；颜色字面量收敛回 `$jzb-*` Token。

## 三、分项优化方案

### 3.1 按钮体系重构（核心，对应"按钮突兀"）

#### 3.1.1 四级动作体系定义

| 层级 | 形态 | 样式 | 使用场景 | 示例 |
|---|---|---|---|---|
| L1 主操作 | 渐变实底按钮（现有 `jz-btn--primary`） | 渐变 + 投影，92rpx，`jz-btn--block` 或 `jz-grow` | 每屏唯一推进动作：提交、生成、确认、开始 | 生成报价 / 合同生效 / 提交验收 / 开始下一阶段 |
| L2 次级操作 | 浅底 / 描边按钮（`plain` / `ghost` / `neutral`） | 取消、补充信息、并列入口（每屏 ≤2 个） | 编辑资料、保存草稿、查看历史 | 保存草稿 / 查看项目 / 发起变更单 |
| L3 图标按钮 | 统一 `JzIconButton` 组件（新增） | 64–72rpx 视觉 + ≥88rpx 触控区，浅底圆形/圆角 | 高频通用动作：电话、复制、编辑、删除、更多、返回 | 电话 / 复制 / 编辑 / 删除 / 更多 |
| L4 文字链接 | 文字 + 可选小图标（`jz-btn--text` / section__more） | 26rpx 品牌色，用于列表行尾与区块头 | 低优先级入口：写跟进、新增房屋、查看方案 | 写跟进 / 新增房屋 / 查看方案 |

- `view` 冒充按钮的 31 处：全部改为 `<button>` 或收敛进组件（获得原生 loading/disabled 语义与 :active 反馈）。
- 按钮 icon+文字混排时图标统一 24–28rpx，间距 8rpx（已有 `.jz-btn .jz-icon + text` 规则，补充图标按钮场景）。

#### 3.1.3 "图标代替按钮"的效果评估（用户关注点）

**收益（可量化预期）**
- **视觉降噪**：高密度页按钮数量下降约 40–55%（19→8、16→8），一屏从"色块阵列"变为"一个焦点 + 若干辅助"，用户首屏决策时间缩短。
- **层级正确**：唯一 primary 被真正突出，业务推进路径（下一阶段动作）不再被次要按钮稀释。
- **空间释放**：详情页操作区高度压缩，关键信息（状态、金额、进度）上移进入首屏。
- **高频动作效率**：电话/复制/编辑等高频动作从"找文字按钮"变成"肌肉记忆定位图标"，单手操作更顺。

**风险与边界（必须同时落实）**
- **图标认知成本**：业主（尤其中老年）与一线工长对抽象图标识别弱 → 铁律：**业务动作图标必须带文字**（图标+文字双通道），纯图标仅限电话/复制/编辑/删除/关闭/更多/搜索/返回 8 类通用动作。
- **触控区**：纯图标按钮视觉 64–72rpx，但触控区必须 ≥88rpx（padding 补齐），否则误触率上升。
- **不可图标化**：表单提交、危险操作（删除/驳回/终止）、不可逆操作（合同生效、验收确认）、金额相关操作——这些必须保持完整文字按钮 + 二次确认。
- **一致性**：同一动作全工程同形（如"删除"统一 trash 图标 + 红色），不在一处用图标一处用文字。

### 3.2 图标体系补全

**新增 `JzIconButton.vue` 组件**（消除 31 处手写 + 尺寸/圆角不统一）

```text
Props: name(IconName) / size(默认 64rpx 视觉) / tone(primary|neutral|danger) / shape(circle|rounded)
       disabled / badge(可选角标数字) / text(可选，图标下方小字)
尺寸: 视觉 64rpx（小号）· 72rpx（默认）；触控区一律 88rpx（padding 外扩）
反馈: :active → scale(0.96) + 背景加深（danger 加深红底 12%）
语义: 无 text 时组件强制要求 aria-label/可访问文本（小程序侧用可识别 text 占位）
```

**补齐 JzIcon 图标清单**（现有 48 个，建议新增 18 个）：

| 类别 | 新增图标 |
|---|---|
| 操作类 | `trash` 删除、`eye / eye-off` 可见性、`clock` 逾期/历史、`history` 变更记录、`upload` 上传、`download` 下载、`share` 分享、`send` 发送、`lock` 锁定、`more-vertical` 更多 |
| 业务类 | `doc` 合同、`calculator` 算量、`scan` 扫码、`truck` 材料进场、`star` 评价、`pause` 停工 |
| 导航类 | `arrow-left` 返回、`external` 外链 |

补充后 `IconName` 联合类型同步扩展，保持 `JzIcon` 单一来源。

### 3.3 底部操作条统一（21 个页面）

- 抽出统一语义：`JzActionBar`（或收敛回 `base.scss` 的 `.jz-actionbar` 一套实现 + 插槽）。
- 规范固化：白底毛玻璃（`rgba(255,255,255,.97)` + blur）、上边框 + 弱上投影、高度 `112rpx + safe-bottom`、按钮 gap 14rpx、主操作 `grow`、次操作固定宽度。
- H5 560px 居中适配收进组件一次实现，删除 `base.scss` 中为私有类（`.ce__foot/.cm__foot/.cd__foot/.qe__foot/.te__foot/.rp__foot/.pc__foot/.pe__save-fixed`）打的补丁。
- 替换路径：先替换形态最杂的 `customer/detail`、`quote/detail`、`project/plan`、`catalog/manage`，再批量替换其余 17 个页面（纯机械替换，低风险）。

### 3.4 页面节奏与层级

1. **首页信息降载**：8 模块 → 6 模块（"需要关注"折叠见 3.1.2-⑥）；指标卡、快捷入口保持 2 列 / 5 宫格；模块间距统一为 `$jzb-page-gap` 的 1.5 倍（36rpx）以建立层级。
2. **Header 分级**：Tab 工作台保留渐变头（品牌识别）；详情页/编辑页 header 改为 `--plain` 浅色或收窄渐变，减少整屏绿块、突出内容。
3. **弹层品牌化**：新增 `JzSheet`（底部半屏，28rpx 大圆角 + 拖拽条）与 `JzActionSheet`（动作面板），替换 5 个页面（`customer/detail` 指派设计师、记录微信/到店；`quote/detail` 发起变更、金额输入；`design/talk`；`mine/index` 关于）的原生 `showModal/showActionSheet`，与全站圆角、动效、安全区一致。
4. **详情页分段导航**：`project/detail`、`quote/detail` 等长页面用 sticky 分段导航（`position:sticky`），分区锚点直达。

### 3.5 Token 纪律收敛（425 处字面量）

- 页面样式表内的硬编码颜色（含品牌 hex 134 处）全部替换为 `$jzb-*` 变量；`JzIcon/JzTag` 通过 props 传色属合理场景，但色值必须引用 token（组件内定义语义映射表，页面不再直接写字面量）。
- 页面私有渐变（`#EAF7F5/#F5F2FF/#EEF9F7` 等）收敛到 `$jzb-gradient-soft` 与新增的语义浅底 token。
- 检查机制：交付前 grep 品牌 hex 黑名单（`#16A394/#0E8A7D/#E5484D/#E67E22/#07A35A/#6958C8/#3568C7/#778390/#AEB8C2`），新代码不得再出现。

### 3.6 触控、反馈与状态完备

- **触控区**：所有图标按钮、chip、filter 触控区 ≥ 88rpx（视觉 + padding）。
- **按压反馈**：补齐无反馈的可点卡片（`cd__quote`、`pl__card`、`home__performance` 等），统一 `:active { transform: scale(.988) }` + 背景变化。
- **三态统一**：`JzSkeleton` 从 5 页扩到全部列表/详情首屏；封装 `JzState`（loading → empty → error+重试）收敛裸 `jz-empty` 与 `catch(() => [])` 静默降级（对齐 docs/10 P2）。
- **按钮 loading**：统一使用原生 `<button :loading>`，view 冒充按钮的 31 处改造后自动获得；禁用态保持宽度防跳动。

### 3.7 表单细节（低优先）

- 数字输入右对齐、文本输入左对齐（对齐 docs/03 §5.4）。
- 选择器统一"当前值 + chevron-right"（对齐 spec）。
- 字段错误信息紧邻字段下方（红色 22rpx），现有 `.jz-field` 聚焦态已达标，补齐错误态样式。

## 五、验收标准与效果度量

**定量指标**
- 高密度页按钮数量：customer/detail 19→≤8、quote/detail 16→≤8、design/list 8→≤5。
- 同屏 primary 数量：全部页面 ≤1。
