# 装得清 · 装企一线员工操作手册

> 本手册面向家装企业实际使用装得清小程序的员工（市场、店长、设计师、项目经理、老板）。
> 按"你是谁、你要做什么"组织，遇到 BUG 或流程疑问时，先查这里。
> 业务规则详情见 [business-rules.md](./business-rules.md)，修复历史见 [log.md](./log.md)。

---

## 一、销售跟进阶段（市场/店长视角）

### 1. 新客户刚进店，怎么开始跟进？
1. 客户列表页右下角点**"登记客户"**（绿色悬浮按钮）；
2. 至少填：姓名、电话、来源；
3. 保存后进入客户详情，步骤条停在"到店/跟进"。

### 2. 跟进过程中怎么记录沟通？
- 客户详情页**右下角绿色悬浮按钮"写跟进"**（带对话气泡图标）；
- 每次沟通后立即记录：方式（电话/到店/微信/视频）、内容、下次跟进时间；
- 同一个客户有多套房屋时，"写跟进"是客户级的，不区分房屋。

### 3. 什么时候可以点"约定量房"？
**必须同时满足**：
1. 客户已经有**房屋档案**（在"装修房屋"区块能看到一张房屋卡片）；
2. 这套房屋**还没量过房**（卡片上"最近量房"显示 —）；
3. 客户阶段在"跟进中"或"待量房"。

> ⚠️ 只在客户资料里填了小区名字、没建房屋档案，**不会**出现"约定量房"按钮——这是产品故意设计的，因为量房必须绑定具体门牌地址。

### 4. 客户还没建房屋档案，怎么补？
- 客户详情页"装修房屋"区块右上角点"新增房屋"；
- 必须填**详细地址**（精确到门牌号），否则保存不了；
- 小区、楼栋、房号、面积、户型选填。

### 5. 房屋地址填错了，怎么改？
- 在"装修房屋"横向卡片上，点卡片底部右侧**"编辑"**；
- 改完点"保存房屋"返回详情，卡片自动刷新。

### 6. 已经约定了量房时间，客户改期怎么办？
- 在房屋卡片上找**"已约定 09-22 14:00"**那一行，右侧点**"调整"**；
- 进入量房页后日期时间已自动填好，改完点"确认量房约定"即可；
- 改期不影响客户阶段，仍是"待量房"。

### 7. 客户到店了，怎么记录？
- 客户详情页"跟进记录"上方有两个小按钮：
  - **记录加微信**：客户同意加微信后点；
  - **记录到店 · N 次**：点一下会弹确认框，确认后到店次数 +1。

## 二、待量房阶段（店长/老板视角）

### 1. 什么时候"指定设计师"？
- 客户已经约定了量房时间（房屋卡片显示"已约定 xx"），但还没有接手设计师；
- 客户详情页主按钮会变成**"指定设计师"**；
- 点后弹出当前企业在职设计师列表，选一位即可。

### 2. 量房时间到了，谁去量？
- 设计师按约定时间上门；
- 量完后由设计师或项目经理在系统里"录入量房"（拍照、原始结构、尺寸、客户诉求）；
- 录入后房屋卡片"最近量房"会更新，状态从"待量房"变成"已量房"。

## 三、设计与报价阶段（设计师/店长视角）

### 1. 量完房后做什么？
- 主按钮变成**"进入设计转化"**；
- 设计师在设计转化模块里整理客户诉求、出方案、做谈单 PPT。

### 2. 怎么生成报价？
- 设计转化完成后主按钮变为**"生成报价"**；
- 报价提交后客户会收到待确认通知。

### 3. 报价客户已接受或已转项目？
- 主按钮变成**"查看报价"**，点击进报价详情；
- 报价转项目后，客户详情会显示**"查看工地"**，点击进入工地进度页。

---

## 四、施工履约阶段（项目经理视角）

### 1. 怎么看自己在管的工地？
- 项目经理角色默认进入"履约驾驶舱"；
- 客户详情里如果该客户已转项目，主按钮是"查看工地"。

### 2. 关键提醒
- 客户详情页**只显示当前客户自己的工地**；
- 如果发现"跟进中客户"显示"查看工地"按钮，或者点进去看到的是别人客户的工地，**立刻截图联系技术**——这是数据串号事故（参考 FIX-001）。

## 五、常见问题 FAQ

### Q1：为什么客户资料里填了地址，还不能约定量房？
A：客户资料的"意向小区/地址"是线索级信息，量房必须绑定**房屋档案**（精确到门牌号）。请到"装修房屋"区块点"新增房屋"补齐。

### Q2：为什么我的客户详情没有"写跟进"按钮？
A：两种可能：
1. 你没有"跟进客户"权限（只有市场、店长、老板等角色有）；
2. 当前主按钮本身就是"写跟进"，右下角悬浮按钮自动隐藏避免重复。

### Q3：约定错了量房时间怎么改？
A：房屋卡片上点"已约定 xx 调整"，重新选时间保存即可。

### Q4：客户有两套房子，量房信息记在哪一套？
A：客户详情页"装修房屋"是横向卡片，**点哪张卡，哪张就是当前房屋**。所有量房/设计/报价都挂在选中房屋上。切换卡片即可切换操作对象。

### Q5：怎么判断这套房子有没有量过？
A：房屋卡片上看：
- "最近量房 2026-09-20" → 已量房；
- "最近量房 —" → 未量房；
- "已约定 09-22 14:00 调整" → 已约定但还没量。

### Q6：点"查看工地"进去是别的客户怎么办？
A：这是 P0 级 BUG，立即：
1. 截图当前客户姓名、点"查看工地"前的页面；
2. 联系技术排查（参考 FIX-001 的根因：项目列表未按客户过滤 + 前端兜底串号）。

## 六、给老板/店长的检查清单（每周巡店用）

- [ ] 客户详情主按钮是否符合当前阶段（跟进中不应出现"查看工地"）；
- [ ] 每个客户的房屋卡片是否都有详细地址；
- [ ] 已约定量房时间的客户，是否都按时录入了量房结果；
- [ ] 待量房客户是否都已指定设计师；
- [ ] 点几个客户的"查看工地"，确认进的是对应客户的工地，没有串号。
