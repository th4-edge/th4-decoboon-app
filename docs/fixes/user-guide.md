# 装得清 · 装企一线员工操作手册

> 本手册面向家装企业实际使用装得清小程序的员工（市场、店长、设计师、项目经理、老板）。
> 小程序内使用帮助中心：`我的 → 使用帮助`，按当前岗位提供上手步骤和常见问题处理。
> 按"你是谁、你要做什么"组织，遇到 BUG 或流程疑问时，先查这里。
> 业务规则详情见 [business-rules.md](./business-rules.md)，修复历史见 [log.md](./log.md)。

---

## 一、销售跟进阶段（市场/店长视角）

### 1. 新客户刚进店，怎么开始跟进？
1. 客户列表页右下角点**"登记客户"**（绿色悬浮按钮）；
2. 至少填：姓名、电话、来源；
3. 保存后进入客户详情，步骤条停在"到店/跟进"。

### 2. 跟进过程中怎么记录沟通？
- 客户详情页**右下角绿色悬浮按钮"写跟进"**（带对话气泡图标）；
- 每次沟通后立即记录：方式（电话/到店/微信/视频）、内容、下次跟进时间；
- 同一个客户有多套房屋时，"写跟进"是客户级的，不区分房屋。

### 3. 什么时候可以点"约定量房"？
**必须同时满足**：
1. 客户已经有**房屋档案**（在"装修房屋"区块能看到一张房屋卡片）；
2. 这套房屋**还没量过房**（卡片上"最近量房"显示 —）；
3. 客户阶段在"跟进中"或"待量房"。

> ⚠️ 只在客户资料里填了小区名字、没建房屋档案，**不会**出现"约定量房"按钮——这是产品故意设计的，因为量房必须绑定具体门牌地址。

### 4. 客户还没建房屋档案，怎么补？
- 客户详情页"装修房屋"区块右上角点"新增房屋"；
- 必须填**详细地址**（精确到门牌号），否则保存不了；
- 小区、楼栋、房号、面积、户型选填。

### 5. 房屋地址填错了，怎么改？
- 在"装修房屋"横向卡片上，点卡片底部右侧**"编辑"**；
- 改完点"保存房屋"返回详情，卡片自动刷新。

### 6. 已经约定了量房时间，客户改期怎么办？
- 在房屋卡片上找**"已约定 09-22 14:00"**那一行，右侧点**"调整"**；
- 进入量房页后日期时间已自动填好，改完点"确认量房约定"即可；
- 改期不影响客户阶段，仍是"待量房"。

### 7. 客户到店了，怎么记录？
- 客户详情页"跟进记录"上方有两个小按钮：
  - **记录加微信**：客户同意加微信后点；
  - **记录到店 · N 次**：点一下会弹确认框，确认后到店次数 +1。

## 二、待量房阶段（店长/老板视角）

### 1. 什么时候"指定设计师"？
- 客户已经约定了量房时间（房屋卡片显示"已约定 xx"），但还没有接手设计师；
- 客户详情页主按钮会变成**"指定设计师"**；
- 点后弹出当前企业在职设计师列表，选一位即可。

### 2. 量房时间到了，谁去量？
- 设计师按约定时间上门；
- 量完后由设计师或项目经理在系统里"录入量房"（拍照、原始结构、尺寸、客户诉求）；
- 录入后房屋卡片"最近量房"会更新，状态从"待量房"变成"已量房"。

## 三、设计与报价阶段（设计师/店长视角）

### 1. 量完房后做什么？
- 主按钮变成**"进入设计转化"**；
- 设计师在设计转化模块里整理客户诉求、出方案、做谈单 PPT。

### 2. 怎么生成报价？
- 设计转化完成后主按钮变为**"生成报价"**；
- 报价提交后客户会收到待确认通知。

### 3. 业主在"我的家 · 设计方案 / 报价清单"里能看到什么？
- 每个区域一张卡，**区域全部平铺列出**（顶部有区域索引，点一下跳到对应区域并自动展开），不会再出现"区域多了看不到后面几个"的情况；
- **分项明细默认是收起的**，点区域标题才展开——业主先看"有哪几个区域、各自多少钱"，再逐个核对；
- 每个分项都会单独显示**施工工艺**（品牌色块，写明这套活儿怎么做），下面是验收标准和品牌/规格；
- 工艺内容来自"报价项目库 → 施工工艺"。想让业主看懂报价，先在项目库里把工艺写清楚——写空的分项不显示工艺块（FIX-010 / FIX-011）。

### 4. 施工工艺从哪来、会变吗？
- 在"报价项目库"里维护**施工工艺**字段；
- 新建设计分项、生成报价时，系统会把当时的工艺**冻结快照**到分项和报价行上：之后改项目库工艺，**不会回头改动已经生成的设计方案和报价**（FIX-011）；
- 员工端"方案编辑"的分项卡、"报价详情"的分项行都能看到同一份工艺，设计师和店长讲解时口径一致（列表里的工艺最多显示 3 行，完整内容点开分项查看）。

### 5. 报价客户已接受或已转项目？
- 主按钮变成**"查看报价"**，点击进报价详情；
- 报价转项目后，客户详情会显示**"查看工地"**，点击进入工地进度页。

## 四、施工履约阶段（项目经理视角）

### 1. 怎么看自己在管的工地？
- 项目经理角色默认进入"履约驾驶舱"；
- 客户详情里如果该客户已转项目，主按钮是"查看工地"。

### 2. 主材选材的结果怎么录入、业主看到什么？
- 员工端「主材选材」逐项录入**颜色/花色、规格/型号、品牌/系列、工艺、备注**，点开每项填写后保存草稿或提交客户确认；
- 卡片里的"选材结果"会按字段逐行显示（标签 + 内容）。以前这里（以及业主端"选材记录"）会出现一长串 `{"color":"..."}` 的 JSON，已修复（FIX-012）；
- **选材状态看图标**：对勾图标 = 已确认；时钟图标 = 还没确认（未发起 / 草稿 / 待客户确认都显示时钟，具体状态看后面的文字标签）（FIX-013）；
- 业主端「我的家 · 选材记录」看到的是同一份结果的**中文标签版本**：颜色/花色、规格/型号、品牌/系列、工艺、备注；
- 没填的项目不会显示，所以想让业主看懂，就把关键信息（尤其颜色和规格）填全。

### 3. 关键提醒
- 客户详情页**只显示当前客户自己的工地**；
- 如果发现"跟进中客户"显示"查看工地"按钮，或者点进去看到的是别人客户的工地，**立刻截图联系技术**——这是数据串号事故（参考 FIX-001）。

## 五、常见问题 FAQ

### Q1：为什么客户资料里填了地址，还不能约定量房？
A：客户资料的"意向小区/地址"是线索级信息，量房必须绑定**房屋档案**（精确到门牌号）。请到"装修房屋"区块点"新增房屋"补齐。

### Q2：为什么我的客户详情没有"写跟进"按钮？
A：两种可能：
1. 你没有"跟进客户"权限（只有市场、店长、老板等角色有）；
2. 当前主按钮本身就是"写跟进"，右下角悬浮按钮自动隐藏避免重复。

### Q3：约定错了量房时间怎么改？
A：房屋卡片上点"已约定 xx 调整"，重新选时间保存即可。

### Q4：客户有两套房子，量房信息记在哪一套？
A：客户详情页"装修房屋"是横向卡片，**点哪张卡，哪张就是当前房屋**。所有量房/设计/报价都挂在选中房屋上。切换卡片即可切换操作对象。

### Q5：怎么判断这套房子有没有量过？
A：房屋卡片上看：
- "最近量房 2026-09-20" → 已量房；
- "最近量房 —" → 未量房；
- "已约定 09-22 14:00 调整" → 已约定但还没量。

### Q6：业主端"付款计划"里的钱为什么是"已付 / 待付"？
A：业主端的付款页面统一用**业主口径**：应付总额 / 已付 / 待付，节点状态是待付款 / 部分付款 / 已付清 / 已逾期。员工端财务页面（应收、已收、待收）保持装企台账口径，两边不混用（FIX-014）。付款页顶部还有一张横向的"下一节点"卡片，直接给出节点名、到期日、还差几天和待付金额。

### Q7：业主端"验收整改"的截止日期怎么算的？
A：日期下面会自动跟一个相对提示：未到期显示"还差 N 天"（橙色），到期当天显示"今天到期"，过期显示"已逾期 N 天"（红色）。不用业主自己数日子（FIX-014）。

### Q8：业主在"我的家 · 量房档案"里看到的量房时间是什么格式？
A：统一显示为 `2026-09-10 05:03`（年-月-日 时:分）。以前会显示成后端原始格式 `2026-09-10T05:03:07`（带 T 和秒），已修正（FIX-009）。业主端"量房记录"卡片里，量房设计师用头像卡单独展示，原始结构/尺寸记录等长内容整行铺开，不再被挤成半栏。

### Q9：项目状态和"当前阶段"为什么会打架？
A：以前的 bug：部分页面在取不到阶段名时**硬编码显示"待开工"**，于是出现"状态待验收、当前阶段待开工"的怪组合。现已修复（FIX-015）：
1. "当前阶段"优先显示真实阶段名，取不到就显示项目状态（如"待验收"），不会再写死"待开工"；
2. 开工阶段不再把"待验收/停工"的项目改成"施工中"；
3. 刚开始、任务还没报进度的阶段，不会被刷回"未开始"。

### Q10：项目详情里业主能看什么？
A：业主端项目详情固定五个页签：**进度 / 计划 / 增减项 / 动态 / 建议**（任务、成员是内部视角，业主看不到）。增减项只读、明细在"我的家 · 增减项"；"建议"页签可以提交意见/建议并跟踪处理回复（FIX-015）。

### Q11：项目旅程里"阶段开工 · 开工交底"的日期为什么显示成一串英文？
A：那是历史 bug（FIX-016）：现场汇报的时间用了框架的 `DateTime` 类型，它没有覆写 `toString()`，直接输出就成了 `com.th4.edge...DateTime@xxxx`。已修复，现在统一显示成 `2026-09-24 10:35:00` 这样的正常时间。

### Q12：工地相册现在长什么样？
A：改成**朋友圈式时间线**（FIX-018）：
- 按**天**分组，最新在最上面（今天 / 昨天 / 9月20日 · 周六），每组显示当天记录条数；
- 每条记录保留"谁（姓名+角色）、几点、哪个阶段、做了什么、照片"，点照片可全屏左右滑动；
- 照片按朋友圈规则排：1 张大图、2/4 张两列、其余三列，超过 9 张显示 `+N`；
- 触底可以一直往前翻更早的记录，下拉刷新。

### Q13：项目状态"待验收"和"竣工验收"怎么区分？
A：**不区分**。按 2026-09-24 决策，项目状态 `Accepting` 在**所有页面统一显示"待验收"**（DEC-009 允许"待验收"或"阶段待验收"二选一）；具体是哪个阶段在验收，看项目详情里的"施工阶段进度"和阶段状态。曾做过的"阶段待验收 / 竣工验收"细分已回退（FIX-015）。

### Q14：点"查看工地"进去是别的客户怎么办？
A：这是 P0 级 BUG，立即：
1. 截图当前客户姓名、点"查看工地"前的页面；
2. 联系技术排查（参考 FIX-001 的根因：项目列表未按客户过滤 + 前端兜底串号）。

### Q15：怎么修改员工头像？为什么要在客户和工地里优先看头像？
A：进入「我的 → 个人信息 → 更换头像」，选择微信头像后系统会立即保存到员工档案。员工头像带岗位色点，老板、店长、业务员、设计师、项目经理和财务在客户、工地、任务、验收、设计与绩效页面都能快速识别责任人。未设置头像或图片加载失败时，会显示姓名首字，不会出现空白。【FIX-022】

### Q16：手机号登录后还没加入企业，点“以后再说”会怎么样？
A：本次未归属登录会先退出，然后回到游客首页，您可以继续浏览产品；下次主动登录时会再次询问。这样不会再出现“点了以后再说又被弹回未加入企业页”的情况（FIX-024）。

### Q17：进入「我的家」没找到装修项目，怎么返回或退出？
A：页面底部会显示“返回首页，暂不进入我的家”“切换账号”“我是装修公司员工”“我要注册装修公司”等入口。业主可先回首页浏览；如果换了微信账号，可点“不是当前账号？切换账号”重新登录（FIX-024）。

### Q18：为什么线上所有照片、头像和附件都传不上去，但别的功能正常？

### Q19：只有一批手机号，怎么快速录入客户并交给业务员？
A：进入客户经营页，点右上角“批量录入”，选择客户负责人，再把手机号粘贴进去。系统支持逗号、顿号、分号、空格、换行、斜杠、竖线等分隔，并会先显示“可新增 / 已存在 / 无效”预览；确认后只新增有效号码，客户会自动进入所选业务员的客户范围（FIX-026）。

### Q20：客户原来由别的业务员负责，店长怎么调给新业务员或设计师？
A：进入客户详情，客户负责人和负责设计师均可点击更换。店长只能转交给本门店人员；企业负责人可以按企业范围调整。编辑客户基础资料不会自动改负责人（FIX-026）。

### Q21：批量录错了手机号，怎么删除客户？
A：企业负责人进入客户详情，底部点“删除客户”。只有没有跟进、房屋、设计、报价、合同和项目事实的客户才能删除；已经有业务记录的客户会被系统阻止，避免误删主链数据（FIX-026）。

### Q22：项目经理点“新建任务”后为什么进入工艺任务库？
A：施工任务现在固定按“阶段 × 区域 × 工艺”生成，必须先在企业工艺库选择标准施工项再保存。这样才能保证报价、施工项、验收标准和后续成本使用同一套口径，不允许自由文本绕过（FIX-027）。

### Q23：TeamLeader 没绑定团队时为什么点团队页面会回首页？
A：设计调度、团队成员和团队业绩都依赖团队数据范围。账号未绑定团队时，系统会提示“当前账号未绑定团队，请联系店长或企业负责人”并回首页，避免把权限前置问题误报成加载失败（FIX-027）。

### Q24：登记收款时点“应收节点”为什么先让我选项目？
A：应收节点属于具体项目，系统必须先确定项目，才能正确显示该项目下已登记、且还有待收余额的节点。未选项目时会先进入“选择所属项目”；项目没有应收或全部收清时，表单会直接给出新增或查看应收计划的出口，不再弹出空的系统选择框（FIX-028）。

### Q25：登记付款时怎么选应付单？已结清的还能核销吗？
A：从“财务工作台 → 登记付款”进入后，点“应付单”会打开独立选择页，可按名称、收款方、来源单号搜索，并按待付/逾期/加急、材料款/工人工资/项目款/供应商款/费用支出筛选。默认只列还有待付余额的应付单；打开“显示已付清”只能查看，不能再次核销。从应付账款或工人工资点“安排付款”进入时，应付单和项目/收款方/待付金额会自动带出（FIX-028）。

### Q26：发工资时系统里还没有这个工人的档案，能先付款吗？
A：可以。工资付款的“发放工人”是选填项；未选时系统会提示工资凭证的身份证号、工种、银行账号栏位先留空。付款后到“付款记录”找到“工人待补录”的工资付款，点“补录工人”选择已有档案，系统只关联工人并按原凭证号重打单张工资凭证，不改金额、账户、日期、核销和台账（FIX-029）。

### Q27：为什么付款了项目成本不一定立刻变化？
A：付款只核销应付并形成资金台账支出；项目成本按“应付形成/到货确认”口径归集，材料退货再按规则冲减应付与成本。所以付款金额变化不会重复改变成本总额（FIX-030）。
### Q28：手工记账选收入和支出时，账务用途为什么不一样？
A：账务用途会随收支方向联动。收入只能选“其他收入、资金往来、其他”；支出只能选“项目零星成本、企业费用、资金往来、其他”。如果先选了“其他收入”再切换到支出，系统会自动把不兼容的用途改成“其他”，避免记成“支出 + 其他收入”。项目零星成本仍必须选择所属项目（FIX-031）。


### Q29：设计师 App 首页快捷入口怎么用？
A：设计师首页按“今天先做什么”排序：待我设计、待我报价、合同签约、客户诉求、我的客户、报价池、设计业绩、消息通知。设计师负责发起合同和登记客户签约，提交后由企业负责人或店长复核确认；“报价池”是全部/历史报价列表，底部“报价”Tab 才是我今天要处理的报价。施工项目统一从底部“项目”Tab 进入（FIX-032、FIX-038）。


### Q30：设计师新建报价时怎么选客户、房屋、方案和套餐？
A：现在不再使用系统下拉。点击“客户、客户房屋、设计方案、套餐模板”业务卡会进入对应的专用选择页：客户可按阶段和关键词选，房屋必须带客户上下文显式选择，方案只允许达到可报价条件的方案，套餐可按面积段比较。更换客户后，原房屋、套餐和金额预览会自动失效并重新选择；套餐成本仅企业负责人、店长和财务可见。报价调整页的“基础套餐项目”也改为独立选择页，“报价项目”从企业报价项目库选择（FIX-033）。


### Q31：为什么现在点击现场照片会出现明确提示？
A：现场汇报、录入量房信息、验收整改、变更证据和附件上传现在统一使用同一个照片选择器。它会优先打开微信的拍照/相册选择；如果相机或相册权限没有开启、微信版本不支持，或当前在开发者工具里无法打开系统相册，系统会直接提示原因，不再出现“点了没反应”。真机上首次使用请允许相机/相册权限；如果误点了“不允许”，可在微信设置中重新开启（FIX-035）。

### Q32：客户确认报价后，设计师、负责人或店长怎么完成合同签约和立项？
A：设计师从“合同签约”或签约工作台打开客户，先提交合同签约，冻结客户确认报价、建议付款计划和施工计划；企业负责人或店长复核后可以调整最终签约价、付款计划、施工计划和工期，再确认签约。合同进入已签约状态后仍不创建项目，必须由企业负责人或店长单独“确认生效并生成项目”，系统才会创建唯一项目、施工阶段、材料预计划和应收计划（FIX-038）。


### Q33：我的经营工具里为什么现在所有人都能看到企业模板？

A：报价项目库、套餐模板、付款计划模板、施工计划模板是企业统一标准，所有内部岗位都需要查看，避免一线人员靠个人文件或口头口径工作。企业负责人和店长可以维护；其他岗位只能查看，不能修改、启停、复制或发布。报价项目库的标准成本仅企业负责人和店长可见。我的工资条已从经营工具中拆出，在“我的 → 我的工资”单独查看（FIX-040）。

### 老板：怎么填「企业对外信息」（业主能看到的那 6 项）

路径：我的 → 我的企业 → 「对外服务信息」→ 编辑。

| 字段 | 怎么填 | 常见错误 |
| --- | --- | --- |
| 服务区域 | 写你实际接单的范围，例：合肥市（蜀山区、滨湖新区） | 写「全安徽」但实际不去，业主会觉得不实 |
| 企业客服电话 | **公司统一号码**，例：0551-6558 8899 | 填某个员工的手机号会被拦下（业主端不暴露员工个人号） |
| 售后专线 | 有就填，没有留空 | 和客服电话填同一个号也没问题 |
| 统一社会信用代码 | 营业执照上 18 位 | 少一位、含字母 I/O/S/V/Z 会被拦下 |
| 资质 | 例：建筑装饰装修工程专业承包二级 | 没有资质留空即可，不要写「甲级」这种没有凭证的等级 |
| 一句话简介 | 一句话说清主营与服务承诺 | 不要写夸张承诺（平台不背书，业主会当真） |

另外两项品牌配置：**叙事主品牌**默认「装企」（业主看到的是你们公司）；**记录存证署名**默认不显示，打开后业主端会出现「记录存证与保管 · 装得清」。

填完保存后，业主点开「我的家」即可看到公司名称、客服电话、售后专线和简介；不填的位置业主看到的是「暂不可确认」。

## 七、使用帮助与成功提醒

### 1. 遇到问题时怎么自己解决？
- 页面操作失败后，如果系统识别到常见问题，会弹出“查看解决方法”。
- 点击后直接进入帮助中心对应问题，按“你看到什么、为什么、怎么解决、去哪里处理”操作。
- 也可以从 `我的 → 使用帮助` 搜索或按分类查找。

### 2. 第一次使用不知道做什么？
- 首页启动引导会按当前角色给出下一步。
- 点击卡片底部“不知道这一步怎么做？”进入岗位使用帮助。
- 完成同一任务后返回首页，下拉刷新会重新读取真实业务状态。

### 3. 企业负责人怎么看是否需要运营介入？
- 从 `我的 → 经营工具 → 使用进度` 进入。
- 可查看 7/14/30 天里程碑、企业激活分、岗位业务激活率和流失风险。
- 该看板只读取真实业务事实，不包含登录频次和个人行为监控。
- 发现风险时应先补业务实事，不要为了完成指标直接修改数据库。
