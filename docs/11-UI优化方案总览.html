核心抓手 · 按钮四级动作体系（解决“突兀”与“主次不分”）
L1 主操作 · 每屏唯一
生成报价
推进业务阶段的动作，渐变实底+投影，全宽或 grow
L2 次级操作 · 每屏≤2
保存草稿
取消 / 补充信息 / 并列入口（plain·ghost·neutral）
L3 图标按钮 · JzIconButton 新增
✆ ⧉ ✎
高频通用动作：电话/复制/编辑/更多；触控区≥88rpx
L4 文字链接 · 低优先入口
写跟进 →
列表行尾 / 区块头的低频动作，不占按钮位
图标代替的边界：业务推进类（生成报价/合同生效/提交验收）与危险/不可逆操作禁止图标化；业务动作图标必须“图标+文字”双通道，纯图标仅限 8 类通用动作。
六类问题 → 对策 → 预期效果
① 按钮密度失衡
customer/detail 19 处、quote/detail 16 处；同屏多个 primary
→ 四级分级 + 图标化：高密度页按钮 −40%~55%，同屏 primary ≤1
② 图标体系不完备
JzIcon 仅 48 图标；手写图标容器 60~76rpx 五档并存；31 处 view 冒充按钮
→ JzIconButton + 补 18 图标 + 统一触控区 88rpx
③ 底部操作条碎片化
21 页 ≥4 种实现（jz-actionbar / cd__foot / qe__foot…）
→ JzActionBar 统一，私有类清零，H5 适配收敛
④ 页面节奏过载
首页单屏 8 模块；需要关注最多 8 条；5 页原生弹层
→ 首页 8→6 模块、风险/待办分组折叠、JzSheet 品牌化
⑤ Token 纪律走样
颜色字面量 425 处，品牌 hex 直接出现 134 处
→ 收敛回 $jzb-* 变量，交付前 grep 黑名单拦截
⑥ 触控与反馈
可点卡片部分无按压反馈；图标按钮触控区偏小；骨架屏仅 5 页
→ 触控区≥88rpx、统一 :active、JzState 三态全覆盖
