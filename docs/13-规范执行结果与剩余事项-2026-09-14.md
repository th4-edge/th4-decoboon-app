## 8. 剩余事项

以下事项不阻塞本轮规范执行，但上线前仍需处理：

1. 正式 appid 仍未配置，微信统计提示 `not configured with Appid`。
2. Sass 仍存在 `@import` 与 legacy JS API 弃用警告，后续应迁移到 `@use`/现代 API。
3. 微信登录、业主注册、业主邀请接受、协议隐私页和订阅消息仍未实现。
4. 未覆盖的存量页面仍有颜色字面量和动态内联样式，需后续按页面迭代清理。
5. 首页聚合仍采用多个独立请求；正式数据量上来后应补聚合 Provider。
6. 分页改造已在核心列表落地，部分聚合辅助方法仍保留兼容性上限，只用于工作台摘要，不应再作为业务列表数据源。
7. 需要连接真实后端测试数据完成登录、客户转化、排期、履约、验收和财务全链路联调。
