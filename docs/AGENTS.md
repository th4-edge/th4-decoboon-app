- 不在文档中复制完整业务知识库；只引用正式编号和路径。

## 3. 修复记录

- 修复流程以 `docs/fixes/README.md` 为准。

## 4. 验收边界

- 开发自测、构建、DevTools 和真机体验分别记录。
- 页面证据必须包含角色、租户、路由、页面状态、操作、回读和失败恢复。
- 独立验收预期只来自冻结用例和业务事实，不来自当前实现。
