# 设计转化闭环

小程序将原“套餐报价”改造为方案驱动流程：

```text
客户详情 / 设计报价池
→ 客户诉求
→ 可谈单的主推设计方案
→ 区域长宽高与周长
→ 施工/主材分项
→ 服务端公式汇算
→ 设计报价
→ 谈单 PPT
→ 客户接受
→ 项目施工任务与材料计划
```

## 页面

| 页面 | 路径 | 核心动作 |
| --- | --- | --- |
| 设计转化总览 | `pages/design/list` | 查看五阶段进度、方案与报价 |
| 客户诉求 | `pages/design/requirement` | 记录诉求和排斥点 |
| 设计方案 | `pages/design/scheme` | 维护方案、区域尺寸、施工/主材分项 |
| 谈单 PPT | `pages/design/talk` | 生成、重建、查看页结构和 PPT 下载地址 |
| 设计报价 | `pages/quote/edit` | 选择已完成方案，按折扣生成报价快照 |
| 报价详情 | `pages/quote/detail` | 客户按区域查看，项目经理按施工分类查看 |

## 数据关系

- `DesignScheme` 属于客户和设计师，版本由后端维护。
- 设计转化总览支持复制方案：完整复制区域、分项、图纸和图片；副本自动改名、版本从 `1` 开始且状态回到 `Draft`，不复制报价和谈单记录。
- 设计转化总览支持删除未完成方案：仅 `Draft` 状态显示删除入口，确认后连同区域、分项和图片一并删除；已有报价或谈单记录的方案不可删除。
- 从设计方案进入报价时，客户、房屋和设计方案锁定为只读上下文；只有从“新建报价”独立入口进入时，套餐报价才允许选择客户和房屋。
- 套餐模板由企业负责人在 App「我的 -> 套餐模板」维护；支持套餐基本信息、分区、项目行、数量系数、计价方式、是否包含、是否允许扣减和规则说明。
- 套餐报价生成 Draft 后，可在报价详情进入“调整套餐”，执行扣减、升级、替换或增项，服务端重新计算报价金额与成本。
- 设计方案可在报价确认页选择套餐，形成 `Hybrid` 报价：套餐为基础行，设计分项按 CatalogItem、空间类型和名称匹配，生成“套餐独有、设计新增、数量变化、升级、替换”等差异；待确认差异未处理完不能提交客户。
- 客户驳回的报价保持只读历史，可执行“改版重报”生成新的 Draft 版本。
- `DesignSpace` 属于方案，输入长宽后由后端计算面积和周长。
- `DesignItem` 关联区域、施工/主材分类和计价公式，金额不接受前端直接填写。
- `Quote` 是方案分项快照，客户视图使用 `regionGroups`，项目经理视图使用 `constructionGroups/materialGroups`。
- `TalkPlan` 在主推方案达到可谈单状态且存在对应设计报价后生成，并导出 `.pptx` 到 `outputUrl`。
