# 装得清 App 企业负责人首页产品设计

> 状态：用户已确认方向，开发实现中，待独立验收  
> 范围：微信小程序 BOSS 角色首页、经营动态详情页、BOSS 工作台入口与“我的”入口边界  
> 版本：v1.0  
> 日期：2026-09-20

## 1. 设计目标

企业负责人首页不是功能目录，也不是所有业务列表的拼接页。首页只回答负责人每天最关心的问题：

1. 公司当前经营是否正常。
2. 最需要我关注的风险是什么。
3. 我需要处理或推动的事情是什么。
4. 钱、利润和项目交付发生了什么变化。
5. 下一步进入哪个客户、项目或财务操作。

默认样本为 10–30 人、1–3 店的成长型中小装企；同时兼容没有独立财务岗位、由企业负责人兼任财务负责人的实际情况。

## 2. 真实业务场景

### 场景一：负责人早晨到店后快速巡检

- 使用人：企业负责人。
- 触发事件：早上到店，准备安排当天工作。
- 当前动作：打开工作台。
- 系统下一步：展示四项经营指示灯、需要关注的项目、经营动态和六个高频业务入口。
- 异常处理：指标数据不完整时显示“成本未完整/暂不可判断”，不得用 0 或估算值冒充确定事实。

### 场景二：负责人兼任财务，临时核对回款和付款

- 使用人：企业负责人。
- 触发事件：供应商催款或客户回款到账。
- 当前动作：从首页查看待收、逾期应收、待付或本月现金流信号。
- 系统下一步：进入财务页登记收款/付款，并保留项目、客户和流水关系。
- 异常处理：财务接口失败时明确显示“财务状态暂不可确认”，不得继续沿用旧值。

### 场景三：多个项目同时施工，负责人识别需要介入的项目

- 使用人：企业负责人。
- 触发事件：项目节点逾期、停工、材料异常、验收等待或回款逾期。
- 当前动作：查看“需要关注的项目”。
- 系统下一步：显示风险原因、责任人和建议动作，可进入项目详情处理。
- 异常处理：无风险项目时不重复展示全部项目列表，显示“当前项目运行正常”。

## 3. 信息架构

首页从上到下保持以下顺序：

1. 新企引导导航：首次入驻阶段的一次性引导。
2. 个人名片：身份、企业名称和全公司经营视图说明。
3. 四项经营指示灯：签约额、回款额、项目毛利、在建项目。
4. 经营驾驶舱入口：进入目标、趋势、风险和利润明细。
5. 功能域：六个高频经营动作。
6. 需要关注：现有经营预警行动队列。
7. 需要关注的项目：只展示有风险、需要负责人介入的项目。
8. 经营动态：客户、合同、项目和资金的高信号事件，不再展示普通工地照片流水。

“我的”只负责企业、账号、订阅、组织、配置、个人业务和服务支持，不重复承担经营驾驶舱、设计调度、履约驾驶舱等高频业务入口。

## 4. 四项经营指示灯

| key | 名称 | 主数据 | 健康信号 | 主要去向 |
| --- | --- | --- | --- | --- |
| signedAmount | 签约额 | 本月签约额 | 目标达成、环比、同比 | 经营驾驶舱 |
| receivedAmount | 回款额 | 本月回款额 | 逾期应收笔数、回款目标达成 | 经营驾驶舱/财务 |
| grossProfit | 项目毛利 | 本月可靠毛利 | 成本未完整项目、负毛利、目标达成 | 经营驾驶舱 |
| activeProjectCount | 在建项目 | 当前在建项目数 | 停工、计划逾期、待验收 | 项目 Tab/驾驶舱 |

### 状态规则

- `normal`：绿灯，数据完整且处于正常范围。
- `attention`：黄灯，需要负责人关注。
- `danger`：红灯，存在逾期、停工、负毛利等明确异常。
- `unknown`：灰灯，数据不完整，暂时不能可靠判断。

具体规则：

- 毛利不完整：`unknown`，文案为“成本未完整”。
- 签约目标达成低于 60%：`danger`；60%–79.9%：`attention`；80% 及以上：`normal`。
- 未设置签约目标时，按月环比判断；环比低于 -20% 为 `attention`，否则为 `normal`，并明确显示“未设置目标”。
- 回款存在逾期应收：`danger`；无逾期但回款目标达成低于 60%：`attention`。
- 毛利为负：`danger`；毛利完整但目标达成低于 80%：`attention`。
- 在建项目存在停工或计划逾期风险：`danger`；否则为 `normal`。

## 5. 功能域

BOSS 首页功能域固定为六个高频经营动作：

1. 客户管理。
2. 设计调度。
3. 方案报价。
4. 合同签约。
5. 履约驾驶舱。
6. 财务总览。

成员、团队、报价项目库、套餐模板、供应商配置、订阅权益、账号密码等低频配置入口归入“我的”。“经营驾驶舱”保留首页独立入口，不在功能域重复。

在六个一级功能域下方增加负责人专属的二级「经营专业工作台」区，固定提供量房经营、选材工作台、材料计划、增减项经营四个直达入口。该区域不增加第七个一级功能域，量房、选材、材料和增减项仍分别归属客户、项目、供应链和合同履约主线。

## 6. 需要关注的项目

首页项目区块不再读取和展示全部项目，只展示经营预警聚合后的风险项目，最多 4 个。

每个项目显示：

- 项目名称和编号。
- 项目状态与当前进度。
- 最高风险级别。
- 风险原因。
- 项目经理。
- 建议下一步动作。
- 可下钻的项目详情入口。

风险来源：

- 逾期应收。
- 项目停工或计划逾期。
- 材料超领。
- 合同变更率异常。

无风险项目时展示“当前项目运行正常”，不重复项目 Tab 的全量列表。

## 7. 经营动态

经营动态用于告诉负责人“最近发生了什么高信号业务事实”。它不替代工地同频动态，也不展示普通现场打卡和重复施工照片。

### 事件分类

| 分类 | 事件 |
| --- | --- |
| 客户 | 新增客户、客户跟进、报价提交、客户接受报价、客户驳回报价 |
| 合同 | 合同签约、合同生效、合同变更 |
| 项目 | 阶段开工、任务完成、施工进展、申请验收、验收通过、验收驳回、现场问题、材料到场、项目通知 |
| 资金 | 收到工程款、项目付款 |

### 展示规则

- 首页展示最近 4 条高信号事件。
- 经营动态详情页最多加载最近 100 条，并支持全部分类、客户、合同、项目、资金筛选。
- 服务端只扫描每类最近 200 条真实历史记录，并按 180 天时间窗过滤，避免首页长期使用后全表扫描。
- 每条事件显示时间、事件类型、标题、业务摘要、客户/项目、负责人和金额（如有）。
- 点击事件进入对应客户、项目、报价或财务对象。
- 首页只展示经营动态，不再展示“同频动态”的施工照片流。

## 9. 异常与空态

- 微信开发者工具禁止请求 `localhost/127.0.0.1`；本地开发必须使用当前电脑局域网 IP 或 HTTPS 域名，并在修改 API 地址后重新编译。
- 首页接口失败：显示“经营状态暂不可确认”和重试按钮，不清空为 0。
- 经营动态为空：显示“最近 180 天暂无经营动态”，明确说明不会用演示数据填充，并提供新增客户、查看报价、合同签约、登记收款四个起步动作。
- 某个分类为空但其他分类有事件：显示“该分类暂无经营动态”，引导切换分类，不误报为全公司无动态。
- 风险项目为空：显示“当前项目运行正常”。
- 单个指标不完整：该指标显示 `unknown`，其他指标继续展示。
- 无权访问：由服务端统一拒绝，前端不通过隐藏页面替代权限。

## 14. 验收准备数据

建议 acceptance 至少准备以下同一企业内的数据：

1. 一个目标已设置的 BOSS 账号，签约额、回款额有本月和上月事实，可验证目标达成与环比。
2. 一个成本完整、毛利为正的项目，用于验证正常利润灯。
3. 一个成本不完整的项目，用于验证灰灯和“成本不完整”文案。
4. 一个存在逾期应收和停工风险的项目，用于验证红灯、风险原因、责任人与下一步。
5. 一个没有任何风险的项目，用于验证首页不会重复展示全量项目列表。
6. 近期新增客户、提交报价、合同签约或生效、收款、验收等事件，用于验证经营动态时间倒序和分类筛选。
7. 一套接口失败或弱网场景，用于验证“经营状态暂不可确认”和重试恢复。
