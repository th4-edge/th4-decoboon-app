## 1. 目标

App 提供适合移动端的模板查看、复制、轻量编辑、发布、凭证生成和打印，不复制 Web 的复杂编辑器，但与 Web 共享同一模板版本和字段契约。

## 2. 页面结构

```text
财务
  -> 凭证模板
      -> 常用模板
      -> 我的模板
      -> 模板详情
      -> 轻量编辑
      -> 版本历史
```

## 4. 页面能力

### 模板列表

- 页签：常用模板、我的模板。
- 筛选：凭证类型、状态、项目或业务场景。
- 列表项显示：模板名、类型、来源、版本、状态、更新时间。
- 操作：查看、复制、编辑、发布、停用。

### 模板详情

- 横向预览，适配手机横屏。
- 来源基础模板、版本、发布人和更新时间。
- 字段与必填标记。
- 历史版本入口。

### 轻量编辑

- 模板名称；
- 字段显隐和顺序；
- 标题、字号、颜色；
- 纸张方向和常见纸张；
- 签字栏；
- 打印参数。
- 桌面端完整编辑能力不在 App 复刻，复杂版式可提示到 Web 继续编辑。

### 凭证生成

- 从资金台账、收款、付款、工资页选择模板。
- 凭证金额取来源事实。
- 生成后预览、分享和打印 PDF。
- 重复生成读取原凭证，不新增凭证实例。

## 5. API 复用

App 使用与 Web 相同的：

- `document/baseline/list`
- `document/voucher-template/page`
- `document/voucher-template/info`
- `document/voucher-template/save`
- `document/voucher-template/update`
- `document/voucher-template/delete`
- `document/voucher/build`

App 不得自己实现模板字段映射、金额公式或版本算法。

## 6. 权限与异常

- BOSS、店长、财务可编辑和发布。
- 财务、出纳按既有权限生成和打印。
- 敏感字段按工人隐私规则脱敏。
- 跨企业、跨店、越权拒绝。
- 网络失败和保存失败显示“暂不可确认”，重新读取服务端版本。
- 模板被停用或历史版本不可用时，保留只读查看和历史重打能力。

## 7. App 验收

- 模板列表、复制、轻量编辑、发布、停用闭环。
- 平台模板只读，必填字段不可删除。
- App/Web 使用同一模板版本、字段和权限。
- 凭证生成、预览、分享和重打正常。
- 横屏编辑器不溢出，关键字段可操作。
- 历史凭证不因模板修改而变化。
