# scripts — 自动化、录屏与发布辅助

> 根 `AGENTS.md` 同时生效。本文件约束 `scripts/**`。

## 1. 录屏与短视频

- 官网短视频、产品演示和过程录屏必须来自微信开发者工具中的真实小程序页面。
- 禁止用 Web、H5、接口回放、Mock 或静态拼帧冒充小程序体验。
- 统一使用 `scripts/recording/run-scenario.mjs` 和场景 JSON 驱动导航、点击、输入、滚动与页面读取。
- 窗口级证据使用 `screencapture -l <windowId>`；成片保留 MP4、SRT、`run.json` 和场景版本。
- 只使用专用测试企业、项目、账号和角色；不得使用真实客户隐私数据。

## 2. 写操作边界

- 默认只做无副作用浏览、截图和录屏。
- 签约、付款、验收确认、邀请、消息发送和删除必须单独授权，并定义数据清理/回滚。
- 正式小程序提审和发布由用户本人完成；脚本不得点击提交审核或正式发布。

## 3. 脚本质量

- 新增脚本必须有参数校验、失败退出码、关键日志和可重复运行能力。
- 不得把临时 cookie、token、密码、真实用户数据和绝对本机路径写入仓库。
- 修改小程序包、环境变量或版本号时，先检查 `package.json` 现有脚本，不新增同义命令。
- 交付前运行受影响脚本的 dry-run/契约检查；录屏脚本至少做一次无录制预演。
